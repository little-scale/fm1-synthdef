# Five-minute demonstration

1. Install the release and load the example bank using QUICKSTART. Keep MASTER low initially.
2. Select Keys, play a two-note chord, and turn knobs 1–2 to demonstrate cutoff and resonance changing held notes.
3. Press FX to latch effect control, then turn physical knobs 1–2 to change echo amount/time. Release the keys and hear the tail continue.
4. FX code is visible while FX is on; the keyboard still plays Keys. SELECT scrolls the source. ALGORITHM selects another effect. Press FX again to return to synth controls.
5. Select Two-op FM. Start with knob 2 low, then increase it to hear the sine gain sidebands. Sweep knob 1 for changing frequency ratios.
6. In the browser, choose slot 4, change the FM envelope release from 0.45 to 0.8, compile, save locally and send to slot 4. Wait for readback confirmation, then play the longer release.
7. Restore the supplied `two-op-fm.fmslot` if desired. Local editing and device transfer are separate explicit steps.

This is a demonstration script, not a claim that a public demo video has been recorded. The release includes a short host-rendered Two-op FM audio preview in `media/`; it is not a microphone recording of the hardware.
