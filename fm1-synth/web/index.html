Writing a patch
Return one SynthDef(\name, { … }) expression. Compilation executes your code in the installed SuperCollider. Imported .scsyndef files play without source; original code cannot be recovered from them.
Use freq, amp, gate and knob1–knob4. Velocity sets amp to 0–1, so include your desired output attenuation inside the patch. Use Lag.kr to smooth knobs.
Slot 0 reads the mixed stereo synth signal with In.ar(0, 2) and writes its processed output with Out.ar(0, signal). It runs continuously. Select bypass with ALGORITHM to play dry. Synths receive knob1–knob4; effects receive knob5–knob8. Press FX to toggle the physical knob bank. ALGORITHM selects an effect or bypass; PRESETS selects the playable synth.
